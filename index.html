髙山・先方に決めてもらうこと。GitHub の Issue（ラベル「判断待ち」）を1件1枚で出します。

準備中

GitHub のトークンを貼ってください

このボードは、ブラウザから GitHub の Issue を直接読み書きします。初めの1回だけ、このリポジトリの Issue だけを読み書きできるトークンを作って、下に貼ってください。

  1. GitHub に funai-ryo-takayama でログインした状態で、トークンの作成画面（github.com/settings/personal-access-tokens/new）を開く。名前（判断待ちボードと今日の日付）・Resource owner（funai-ryo-takayama）・Expiration（90日）・Permissions の Issues（Read and write）が、はじめから入っています。
  2. Repository access で Only select repositories を選び、 だけを選ぶ（ここだけは自分で選びます）。
  3. いちばん下の Generate token を押し、出てきた github_pat_… をコピーして、ここに貼る。

入っていないときは手で：Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Resource owner は funai-ryo-takayama、Permissions で Issues を Read and write（Metadata は自動で Read-only）。ほかの権限は付けない。期限が切れたら作り直して貼り直します。

トークンはこのブラウザの中（localStorage）にだけ置き、画面やファイルには出しません。消すときは右上の［トークンを消す］。GitHub 側で取り消すときは、同じ設定画面の Fine-grained tokens から Delete します。
